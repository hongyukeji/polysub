本次更新提供 `polysub install` 命令，把应用复制到「应用程序」。

## 更新内容

### 新增

- `polysub install`：把 PolySub.app 复制到「应用程序」，保留签名，不加隔离标记；`brew upgrade polysub` 后再运行一次即可更新。没有写入权限时可以用 `--dest ~/Applications`。

## 下载与安装

要求 **Apple Silicon Mac、macOS 13 或更高版本**。

| 文件 | 用途 |
| --- | --- |
| [polysub-0.3.1-macos-arm64.zip](https://github.com/hongyukeji/polysub/releases/download/v0.3.1/polysub-0.3.1-macos-arm64.zip) | 完整应用（含命令行），解压后拖进「应用程序」 |
| [checksums.txt](https://github.com/hongyukeji/polysub/releases/download/v0.3.1/checksums.txt) | 下载完整性校验 |

安装方式见 [README](https://github.com/hongyukeji/polysub#安装)。Homebrew 安装的是当前最新版，不是这个历史版本。

## 升级说明

Homebrew 用户：`brew upgrade polysub`，然后运行 `polysub install`。

## 验证与限制

- 自动化验证：[发行 CI](https://github.com/hongyukeji/polysub/actions/runs/36107737411) 通过（10 项测试、打包、签名校验）；tap 配方在 macOS 上安装测试通过。
