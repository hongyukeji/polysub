本次更新让 PolySub 开箱即用：App 自带本机识别和翻译引擎，装好后下载一次模型就能生成字幕，不再需要另装 oMLX 或填写 API Key。界面也按 macOS「系统设置」的风格重做。

## 更新内容

### 新增

- **内置引擎**：App 自带 llama.cpp（识别和翻译）和 whisper.cpp，需要时在本机启动，空闲 10 分钟后自动退出。App、后台队列和命令行共用同一个引擎。
- **语音识别改用 Qwen3-ASR**：日语人名和称呼识别更准，也更快。实测 11 分钟语音 22 秒识别完，Whisper turbo 要 49 秒。
- **按内存推荐档位**（公开测试片段上实测）：
  - 32 GB 及以上：「高质量」，翻译用 Qwen3 30B-A3B（混合专家模型，速度接近 4B，译文最自然）。
  - 16–24 GB：「标准」，用 Qwen3 8B。
  - 8 GB：「轻量」，用 Qwen3 4B。
- **首次打开引导**：显示推荐档位，可选下载源（官方或国内镜像），下载可以放到后台；下载期间拖进来的视频会排队等待。已经装了 oMLX 的，可以直接选「使用本机已有的 oMLX（不用下载）」。
- **「模型」页**：查看、下载、删除内置模型，做环境检查，查看文件位置。可以更改模型文件夹（例如换到外接硬盘）。LM Studio、Hugging Face、llama.cpp 缓存里已有的相同 GGUF 文件会直接使用，不重复下载。
- **「我的模型」**：配置自己的高精度组合（例如 oMLX 上的大模型或云端服务），在任务页「翻译质量」里一键切换。从旧版本升级时，原来的 oMLX 设置会自动放进这里。
- **其他**：任务列表支持全选 / 取消全选；已完成的任务可以右键「用其他质量重新翻译」（识别结果直接复用）；新增监视文件夹（新出现的视频自动加入队列）；内置引擎可以加载自己的 GGUF 文件。

### 改进

- **译文不再错行**：成批翻译时，大模型会把句子挪到别的字幕行。现在不思考时每行单独请求、同时翻 4 行，速度不变。在公开测试片段上，错行从约九十分之十降到零。
- **翻译更稳**：温度降到 0.3；给模型看后面 2 行作参考；与下一行内容重复的行会单独重译。另有质量辅助功能，每项都能单独关闭：术语表、更严格的翻译要求、检查译文并重译等。
- **长片支持**：内置翻译引擎的各路请求共用一个上下文池；超长字幕稿在生成翻译参考时均匀摘取片段，几个小时的片子也不会超出上下文。
- **第二遍识别只在需要时进行**：只重识别含人名、称呼或疑似同音错字的片段。
- **界面**：侧栏带彩色图标，内容区接近白色，使用圆角卡片和 macOS 开关；深浅色切换正常；设置分为常用和高级两层，改动自动保存。

### 修复

- 内置翻译引擎的输出曾经全部是乱码：流式返回没有声明字符编码，被当成 Latin-1 解码。
- llama-server 的 JSON 语法约束中途出错时，整个任务都会失败；现在会去掉语法约束重试。
- 第二遍识别把人名提示词读进台词时，保留第一遍的结果。
- 首次引导打开时 ⌘Q 不起作用；退出时可能要等几分钟的网络检查。

## 下载与安装

要求 **Apple Silicon Mac、macOS 13 或更高版本**。模型不在安装包里，首次使用时下载：轻量约 5 GB，标准约 7.5 GB，高质量约 19 GB。

| 文件 | 用途 |
| --- | --- |
| [PolySub-0.4.0-macos-arm64.zip](https://github.com/hongyukeji/polysub/releases/download/v0.4.0/PolySub-0.4.0-macos-arm64.zip) | 完整应用（含命令行和内置引擎），解压后拖进「应用程序」 |

选择一种安装方式：[Homebrew](https://github.com/hongyukeji/polysub#方式一通过-homebrew-安装) · [下载发行包](https://github.com/hongyukeji/polysub#方式二下载发行包安装) · [源码构建](https://github.com/hongyukeji/polysub#方式三从源码构建)。

## 升级说明

- Homebrew 用户：先退出 PolySub，运行 `brew upgrade polysub`，再运行 `polysub install`。
- 旧配置会自动迁移：识别和翻译改用内置引擎；原来的 oMLX 或云端组合移到「我的模型」，在任务页「翻译质量」选它即可切回。第一次打开会提示下载内置模型；不想下载的，选「使用本机已有的 oMLX」或「稍后」。
- 设置、队列和缓存都会保留。

## 验证与限制

- 自动化验证：[源码 CI](https://github.com/hongyukeji/polysub/actions/runs/36223110357) 与 [发行 CI](https://github.com/hongyukeji/polysub/actions/runs/36223112013) 通过（92 项测试，从源码编译 llama.cpp / whisper.cpp 引擎，打包，签名校验）。
- 本机验证：M4 Max MacBook Pro（64 GB）、macOS 27。下载草稿发行包，`shasum -a 256 -c SHA256SUMS` 通过，解压后严格签名校验通过，App 内含两个引擎程序。以全新用户配置运行：自动选中高质量档（Qwen3-ASR + Qwen3 30B-A3B），`doctor` 各项正常；用发行包处理 11 分钟的公开日语访谈（CC BY 3.0），自动识别出日语，全流程 121 秒（含首次加载模型，翻译 38.7 秒）。
- 限制：16 GB 和 8 GB 档位只在 64 GB 的 Mac 上模拟验证过（按对应内存限制运行），还没有在真实的小内存机器上跑过。
- 签名与公证：ad-hoc 签名，未经过 Apple 公证。
