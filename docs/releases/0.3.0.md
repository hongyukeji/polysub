PolySub 的第一个公开版本：独立的 macOS 应用，通过 Homebrew 安装。

## 更新内容

### 新增

- 独立的 `PolySub.app`：自带 Python、Qt、PyAV 和 ONNX Runtime，不需要另装 ffmpeg；可以把视频拖到窗口或 Dock 图标上。
- 字幕编辑器：原文和译文逐行对照，可以搜索、手改、选中行重新翻译。
- 「环境」页：检查音频解码、接口和模型；本机 oMLX 缺语音识别模型时一键下载。
- 接口预设：本机 oMLX、DeepSeek、阿里云百炼、OpenAI、Ollama、LM Studio。
- 通过 [hongyukeji/homebrew-tap](https://github.com/hongyukeji/homebrew-tap) 安装。

## 下载与安装

要求 **Apple Silicon Mac、macOS 13 或更高版本**。

| 文件 | 用途 |
| --- | --- |
| [polysub-0.3.0-macos-arm64.zip](https://github.com/hongyukeji/polysub/releases/download/v0.3.0/polysub-0.3.0-macos-arm64.zip) | 完整应用（含命令行），解压后拖进「应用程序」 |
| [checksums.txt](https://github.com/hongyukeji/polysub/releases/download/v0.3.0/checksums.txt) | 下载完整性校验 |

安装方式见 [README](https://github.com/hongyukeji/polysub#安装)。Homebrew 安装的是当前最新版，不是这个历史版本。
